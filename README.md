Arken Store 

Адаптивный интернет-магазин одежды с корзиной, фильтрацией, сортировкой и поиском.  
Проект демонстрирует навыки фронтенд-разработки: HTML, CSS, JavaScript, LocalStorage.

Демо
[Посмотреть проект](https://muratjan18.github.io/Arken-store/)

Функционал
- Каталог товаров с карточками
- Фильтрация по категориям (Все, Женское, Мужское, Детское)
- Поиск товаров по названию
- Сортировка по цене
- Добавление в корзину
- Увеличение/уменьшение количества
- Удаление из корзины
- Сохранение корзины в LocalStorage
- Адаптивная вёрстка (мобильные, планшеты, десктопы)

Стек технологий
- HTML5
- CSS3 (Flexbox, Grid, медиазапросы)
- JavaScript (ES6+)
- LocalStorage


Структура проекта


├── index.html          # Каталог товаров
├── cart.html           # Корзина
├── CSS/
│   └── style.css       # Основные стили
├── JS/
│   ├── main.js         # Логика каталога
│   └── cart.js         # Логика корзины
└── images/             # Изображения


Как запустить
1. Скачай проект
2. Открой index.html в браузере
